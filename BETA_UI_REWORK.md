# FiercyLauncher 1.0.0.4 — переработка интерфейса

## Что изменилось

1. Раздел «Моды и сборки» открывается на каталоге готовых сборок Modrinth.
2. Верхняя панель раздела содержит три понятных действия: «Каталог сборок», «Создать сборку», «Мои сборки».
3. После создания сборки лаунчер переводит пользователя в «Мои сборки».
4. Моды, ресурспаки и шейдеры устанавливаются в выбранную сборку; готовые `.mrpack` можно просматривать и устанавливать без предварительного профиля.
5. Modrinth автоматически загружает следующие страницы по мере прокрутки. Ручная кнопка «Показать ещё» убрана.
6. На главной странице выбора игры отображаются обычные версии как `Minecraft <версия>`, а установленные пользовательские сборки — по их названию.

## Проверки

- `python -m compileall -q .` — успешно.
- `python -m unittest discover -s tests -v` — 15/15 успешно.
- PyQt5 отсутствует в среде сборки; GUI smoke-test, визуальная проверка на разных DPI и реальный запуск Minecraft должны быть выполнены на Windows.

## Сборка Windows

На Windows с Python 3.12 установите зависимости из `requirements.txt`, затем запустите `build_windows.bat`.
